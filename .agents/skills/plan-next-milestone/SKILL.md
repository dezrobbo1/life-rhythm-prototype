# Plan next milestone

1. Read [AGENTS.md](../../../AGENTS.md) and its ordered authorities, [CURRENT_STATE.md](../../../CURRENT_STATE.md), live main/open PRs/issues/recent merges, and [MVP_PLAN.md](../../../MVP_PLAN.md)'s current programme. Follow the [access workflow](../../../docs/CODEX_WORKFLOW.md).
2. Verify local/source correspondence to live main. Challenge sequencing against dependencies, unfinished acceptance and active PRs; do not duplicate work or infer completion from historical evidence.
3. Identify the next already-authorized bounded slice. Produce a contract containing authority/gate, outcome, non-goals, affected boundaries, acceptance, tests/builds, human dependencies and route from [model policy](../../../docs/CODEX_MODEL_POLICY.md).
4. Use [human gates](../../../docs/HUMAN_GATES.md) for material conflict/reordering/product judgment. Otherwise resolve routine choices within authority.

Output the contract and factual blockers. Do not implement the application or create a parallel roadmap. If no approved slice is available, report the boundary rather than inventing work.
